# Room Security FSM

A digital room security system using FSM in CircuitVerse. Tracks wrong password attempts, displays count on a hex display, and triggers an alarm after 2 incorrect entries.

## Tools Used
- CircuitVerse
- D Flip-Flops, AND/OR gates
- Seven Segment / Hex Display
